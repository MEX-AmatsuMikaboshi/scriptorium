## Qué es
`animate(objetivo, {propiedades, duration, ease, delay: stagger(50)})`, `createTimeline()`, utilidades SVG para dibujar trazos y morphing (v4).

## Úsalo para
- Alternativa MIT a GSAP para letras escalonadas y SVG en páginas web.

## Instalación
```bash
npm i animejs
```

## Limitaciones
- Reloj propio: en video, pausar y posicionar con `seek()` por cuadro.
