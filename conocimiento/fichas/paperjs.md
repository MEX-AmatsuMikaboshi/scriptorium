## Qué es
Port de Scriptographer: `Path`, `Group`, booleanas (unir, restar, intersecar), `path.getPointAt()`, simplificar y suavizar.

## Úsalo para
- Geometría vectorial precisa: dividir figuras, puntos a lo largo de un trazo, morphing con muestreo.

## Instalación
```bash
npm i paper
```

## Limitaciones
- API antigua (sin TypeScript nativo); versión 0.12–0.16 desde hace años.
