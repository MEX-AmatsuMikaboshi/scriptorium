## Qué es
Envuelve un sketch de Canvas/WebGL con tamaño en unidades físicas, `time`/`playhead` deterministas y exportación de PNG por cuadro o MP4 con su CLI.

## Úsalo para
- Loops generativos exportables cuadro por cuadro.

## Instalación
```bash
npm i -g canvas-sketch-cli   # o npx canvas-sketch-cli
```

## Limitaciones
- Beta desde hace años; mantenimiento esporádico.
