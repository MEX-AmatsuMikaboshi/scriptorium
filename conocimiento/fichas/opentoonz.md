## Qué es
Suite de producción de animación 2D tradicional; Toonz fue usado en estudios como Ghibli (según su historia pública).

## Úsalo para
- Anime 2D tradicional dibujado (etapa futura).

## No lo uses para
- Videos explicativos.

## Limitaciones
- Requiere dibujar: un agente no sustituye al animador.
- La API de scripts es limitada y poco documentada.

## En este equipo
No instalado.
