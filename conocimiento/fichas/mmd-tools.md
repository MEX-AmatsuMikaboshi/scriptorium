## Qué es
Lleva el ecosistema MMD a Blender. Versión 4.x para Blender 4.2–5.2.

## Úsalo para
- Aplicar movimientos VMD existentes (baile, gestos) a un personaje.

## Instalación
Blender → Get Extensions → «MMD Tools».

## Limitaciones
- Cada modelo y cada movimiento MMD trae términos propios, a menudo restrictivos (sin uso comercial, crédito obligatorio).
