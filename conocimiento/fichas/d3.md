## Qué es
Módulos independientes: `d3-scale`, `d3-shape`, `d3-hierarchy`, `d3-force`, `d3-geo`, `d3-interpolate`. Para video se usan solo los cálculos (escalas, rutas SVG) y React dibuja.

## Úsalo para
- Gráficas de barras/líneas animadas, árboles genealógicos o de conceptos, mapas con proyección.
- `d3-interpolate` para interpolar colores, números y cadenas con números.

## No lo uses para
- Sus transiciones (`selection.transition()`) dentro de Remotion: dependen del reloj.

## Instalación
```bash
npm i d3-scale d3-shape d3-hierarchy   # solo los módulos necesarios
```

## Ventajas
- Cálculo preciso y probado de escalas, layouts y geografía.
- Módulos pequeños, ISC.

## Limitaciones
- Curva de aprendizaje; el patrón de «selecciones» no aplica en React: usar solo los cálculos.
