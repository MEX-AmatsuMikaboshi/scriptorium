## Qué es
Colección de componentes: `useGLTF`, `Text`/`Text3D`, `Environment`, `ContactShadows`, `Outlines`, `Float`, `MeshDistortMaterial`, etc.

## Úsalo para
- Ahorrar código al meter un modelo glTF con buena iluminación en una escena.

## Instalación
```bash
npm i @react-three/drei
```

## Limitaciones
- Componentes animados por su cuenta (Float, controles) no siguen el cuadro de Remotion: evitarlos o controlarlos a mano.
