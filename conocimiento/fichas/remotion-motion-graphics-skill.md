## Qué es
Skills `motion-graphics` (investigación, referencias, dirección de arte, crítica independiente y autorización de entrega), `cinematic-camera` (un mundo continuo con un rig de cámara con keyframes), `terminal-inserts` (demos de terminal auténticas con ventana 3D) y `article-highlights` (tarjetas editoriales con resaltador de rough.js, desenfoque y rotación 3D sutil).

## Úsalo para
- Aprender criterios de dirección de arte y de cámara que distinguen un video profesional.
- Escenas tipo «artículo resaltado» o «terminal» para videos técnicos.

## No lo uses para
- Estética neón/glow: la skill la prohíbe expresamente (también es buena regla para Scriptorium).

## Instalación
```bash
npx skills add liamrjohnston/remotion-motion-graphics-skill
```

## Ventajas
- Reglas explícitas contra el estilo genérico «hecho por IA».
- Galería de ejemplos hechos por un agente con estas reglas.

## Limitaciones
- Orientada a promos de producto; adaptar a contenido de humanidades.
- Pide investigación y revisión iterativa: pensada para modelos grandes.
