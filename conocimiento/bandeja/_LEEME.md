# Bandeja de entrada

Aquí va todo lo que se junta **tal cual**: conversaciones con otras IAs, listas de enlaces, notas, ideas.
No se edita después: es la fuente original de lo que termina en las fichas.

- Nombre: `AAAA-MM-DD-tema.md` (por ejemplo `2026-11-03-enlaces-shaders.md`).
- Para ver lo pendiente: `saber bandeja`.
- Para procesarla: flujo [agregar-conocimiento](../flujos/agregar-conocimiento.md). Al terminar, la primera línea de la
  nota queda así: `<!-- procesado: AAAA-MM-DD → fichas: a, b, c -->`.

Ojo: el repositorio de Scriptorium es público; lo que se suba aquí con `git push` queda a la vista.
